1. One solid color, as a uniform

The color is a uniform: one value for the whole draw call, sent from JavaScript with gl.uniform3fv. The vertices hold only positions and normals. Nothing about the color is interpolated: every fragment reads the same uColor.

This is the natural choice when a whole object has one color. But a uniform can't change from vertex to vertex, so tab 2 moves the color into the vertex data.

The faces still look different because of lighting: each face points a different way and catches a different amount of light.
