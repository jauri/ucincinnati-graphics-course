3. One color per face

All 6 vertices of a face carry the face's color, and every face gets a different color. Inside each triangle the three vertex colors are equal, so the result is constant and each face is solid. The color changes sharply at the edges.

A cube corner touches 3 faces that want 3 different colors, so each corner is stored 3 times. That is why there are 36 vertices, not 8.
