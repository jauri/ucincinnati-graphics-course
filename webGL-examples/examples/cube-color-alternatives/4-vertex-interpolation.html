4. One color per cube corner (interpolated)

Each of the 8 cube corners has its own color, so the three vertices of a triangle now differ. For every fragment (candidate pixel) the rasterizer interpolates them using barycentric coordinates: color = λ0C0 + λ1C1 + λ2C2, with λ0 + λ1 + λ2 = 1.

The same interpolation happened in tabs 2 and 3. Here you can finally see it. Look for a faint diagonal on each face where its two triangles meet.
