2. One solid color, as an attribute

Exactly the same picture as tab 1, but the code is different: the color is now an attribute, stored with every one of the 36 vertices. The rasterizer interpolates the three vertex colors of every triangle, but interpolating three identical colors gives back the same color, so the whole cube is one color.

Why the longer way? Now each vertex can have its own color. Tabs 3 and 4 use this exact code with different colors.
