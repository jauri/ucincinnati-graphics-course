6. Per-triangle rules

Same as tab 5, but every other triangle uses a different rule. The vertex shader reads the built-in gl_VertexID (0, 1, 2, …, 35) and computes the triangle number, gl_VertexID / 3. It passes that number on as a flat output, so the rasterizer does not interpolate it. The fragment shader then uses one rule for even triangles and another for odd ones.

Each face is two triangles, one even and one odd, so every face shows both rules. Set both menus to the same rule and the cube looks just like tab 5.
