Triangle Drawing Modes

A draw call does two things. First it makes a list of vertex numbers: drawArrays counts up through the vertex buffer, and drawElements reads the numbers from an index buffer. Then the mode groups that list into triangles: TRIANGLES takes 3 at a time, TRIANGLE_STRIP makes each new vertex a triangle with the 2 before it, and TRIANGLE_FAN makes each new vertex a triangle with the first vertex and the one before it.

Each vertex here is 2 floats = 8 bytes; each index is 2 bytes. With more attributes per vertex (colors, normals), storing each corner once saves more.
