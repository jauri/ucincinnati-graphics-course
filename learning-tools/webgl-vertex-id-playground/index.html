Good to know

  • gl_VertexID is the vertex number that was fetched: first + k for drawArrays, and the value indices[k] for drawElements.
  • The fragment shader has no vertex number. It only receives the vertex shader's outputs.
  • WebGL 2 has no gl_PrimitiveID (a triangle number). A flat output is the usual way to give a whole triangle one value.
  • For a flat output, each triangle uses the value of its last vertex, the provoking vertex. (An extension, WEBGL_provoking_vertex, can switch this to the first vertex; this tool keeps WebGL 2's default.)
  • Integer outputs (int, uint) must always be declared flat.
